# SoneFM 업무자동화 — 설치와 사용

개발자가 없어도 방송국에서 계속 쓸 수 있도록 정리한 문서입니다. 문제가 생기면 [인수인계_문제해결.md](인수인계_문제해결.md)를 보세요.

## 누가 무엇을 하나요

| 사람 | 하는 일 | 쓰는 프로그램 |
|---|---|---|
| 국장 | 구글 시트에 업무일지를 씁니다(한 줄에 업무 하나) | 구글 시트 |
| 편성 담당 | 편성표를 짜고, 다 짜면 **데이터 내보내기**로 편성 폴더에 저장합니다 | SoneFM 편성표, 구글 드라이브 데스크톱 앱 |
| 실무자 | 업무자동화 프로그램에서 오늘 업무를 처리합니다. 유튜브 업로드는 직접 합니다 | SoneFM 업무자동화(+편성표, 유튜브 편집기), 구글 드라이브 데스크톱 앱 |

인터넷 서버나 구글 개발자 설정은 쓰지 않습니다. 구글은 **드라이브 데스크톱 앱에 방송국 계정으로 로그인**하는 것만 필요합니다.

## 처음 한 번: 구글 드라이브 준비 (방송국 계정)

1. 방송국 구글 계정의 드라이브에 폴더 두 개를 만듭니다.
   - `SoneFM 업무일지` — 국장의 업무일지 시트를 이 안에 둡니다.
   - `SoneFM 편성` — 편성 담당이 내보낸 편성 파일이 들어옵니다.
2. `SoneFM 업무일지` 폴더 공유를 **"링크가 있는 모든 사용자: 뷰어"**로 바꿉니다. (폴더 안에 새로 만드는 시트도 이 설정을 물려받습니다. 링크를 아는 사람은 업무일지를 볼 수 있다는 뜻입니다.)
3. 업무일지 시트 맨 위에 안내 한 줄을 적어 두면 좋습니다: *"새 업무일지는 이 폴더 안에 만들거나, 이 파일에 탭을 추가해 주세요."*
4. 폴더와 시트의 **주인은 방송국 계정**이어야 합니다. 개인 계정이면 그 사람이 떠날 때 끊깁니다.

## 업무자동화 PC 설치

1. 설치 파일 세 개를 실행합니다. 순서는 상관없고, 관리자 권한도 필요 없습니다.
   - `SoneFM편성표_Setup.exe`
   - `SoneFM-YoutubeEditor-Setup-<버전>.exe`
   - `SoneFM-Platform-Setup-<버전>.exe`
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다(서명 인증서가 없는 프로그램이라 뜨는 창입니다).
2. **구글 드라이브 데스크톱 앱**을 설치하고 방송국 계정으로 로그인합니다. 두 폴더를 오른쪽 클릭 → **오프라인 사용 가능**으로 설정합니다.
3. **SoneFM 업무자동화**를 실행하고 [설정]을 누릅니다.
   - 업무일지 폴더: 드라이브의 `SoneFM 업무일지` 폴더(예: `G:\내 드라이브\SoneFM 업무일지`)
   - 편성 폴더: 드라이브의 `SoneFM 편성` 폴더
   - 앱 폴더: 비워 둡니다(설치한 앱은 자동으로 찾습니다).
4. 오른쪽 "앱" 목록에 **SoneFM 편성표**와 **SoneFM 유튜브 편집기**가 보이면 준비가 끝난 것입니다.

## 편성 담당 PC

1. 구글 드라이브 데스크톱 앱 설치, 방송국 계정 로그인.
2. 편성표를 다 짜면(또는 고칠 때마다) 편성표 앱 **설정 → 데이터 내보내기**를 누르고, 저장 위치를 드라이브의 `SoneFM 편성` 폴더로 고릅니다. 파일 이름은 상관없습니다. 가장 최근 파일을 씁니다.
3. 가능하면 그 달을 **확정**한 뒤 내보내 주세요. 확정 전이면 업무자동화 결과에 "아직 작성중"이라고 표시됩니다.

## 매일 쓰는 법 (실무자)

1. **SoneFM 업무자동화**를 켜면 업무일지와 편성 파일을 자동으로 받아 **오늘 업무**를 보여줍니다. 중간에 새로 받으려면 [새로고침]을 누릅니다.
2. 위쪽 회색 글씨에서 기준을 확인합니다.
   - 업무일지: `<시트 이름> · 마지막 날짜 11/15`
   - 편성: `<파일 이름> (11-14 17:30 받음)`
3. 업무마다 **유형**이 붙습니다.
   - **유튜브 영상 만들기** 같은 유형: [실행]을 누르고, 뜨는 칸을 확인한 뒤 [확인]을 누릅니다. 업무 글자에 "14시"가 있으면 시각이 미리 채워지고, 썸네일은 지난번 것이 채워집니다.
   - **수동**: 프로그램이 처리하지 않는 업무입니다. 직접 하고 [완료]를 누릅니다.
4. 실행하는 동안 진행 막대가 보입니다. 끝나면 오른쪽 **실행 결과**에 버튼이 나옵니다.
   - **유튜브 영상**: [mp4 폴더 열기] → [유튜브 스튜디오 열기]에서 직접 업로드 → [제목 복사]·[설명 복사]로 붙여 넣기.
5. 업무일지에 없는 일은 [업무 추가]로 직접 넣을 수 있습니다(예: `유튜브 화 14시 마을살이`).
6. 결과 기록은 오른쪽 **최근 실행**에 남습니다.

만들어진 영상은 `문서\SoneFM\유튜브\` 폴더에 있습니다. 같은 이름의 `_youtube.txt`에는 제목과 설명이 들어 있습니다.

## 업데이트

새 설치 파일을 그대로 실행하면 덮어 설치됩니다. 데이터(`문서\SoneFM\`)는 지워지지 않습니다.

## 데이터가 있는 곳

| 위치 | 내용 |
|---|---|
| `문서\SoneFM\platform\config.json` | 업무자동화 설정 |
| `문서\SoneFM\platform\platform.db` | 실행 기록, 완료 표시, 직접 넣은 업무 |
| `문서\SoneFM\platform\schedule\schedule.db` | 받은 편성 사본(읽기 전용, 매번 새로 받음) |
| `문서\SoneFM\platform\recipes\` | 현장에서 추가한 업무 유형(레시피) |
| `문서\SoneFM\platform\logs\platform.log` | 문제 해결용 기록 |
| `문서\SoneFM\유튜브\` | 만든 유튜브 영상 |
