# 개발자가 방송국 PC를 떠나기 전 체크리스트

개발자(또는 외부 도움을 준 사람)가 방송국 PC에서 작업을 마치고 떠나기 전에 하나씩 확인합니다. 방송국 직원이 옆에서 같이 확인하면 좋습니다.

## AI 기능 키

- [ ] 개발·데모 목적으로 넣은 Anthropic API 키를 지웠습니다.
  - 업무자동화 → 설정 → AI → **키 삭제**
  - 확인: Windows 검색에서 "자격 증명 관리자" → Windows 자격 증명 → `SoneFM.Platform` 항목이 없어야 합니다(방송국 소유 키를 넣었다면 그것만 남습니다).
- [ ] 방송국이 계속 AI 기능을 쓸 경우, **방송국 계정으로 만든 키**를 방송국 직원이 직접 넣었습니다.
- [ ] 키를 메모장·바탕화면 파일·메신저 등에 적어 두지 않았습니다.

## 계정

- [ ] 개발자 개인 계정(구글, GitHub 등)으로 로그인된 프로그램·브라우저가 없습니다. 구글 드라이브 데스크톱 앱은 방송국 계정입니다.
