# SoneFM 업무자동화 — 문제 해결

화면 맨 위의 주황·빨간 안내와 실행 결과의 문장을 보고 아래에서 찾으세요. 그래도 안 되면 `문서\SoneFM\platform\logs\platform.log` 파일을 개발자(또는 다음 담당자)에게 보내 주세요.

## 업무일지

| 화면 안내 | 원인 | 할 일 |
|---|---|---|
| 업무일지 폴더가 설정되지 않았습니다 | 처음 설치 후 설정 안 함 | [설정] → 업무일지 폴더 지정 |
| 업무일지 폴더를 찾지 못했습니다 | 드라이브 데스크톱 앱이 꺼졌거나 로그아웃됨, 드라이브 문자(G: 등)가 바뀜 | 작업 표시줄의 드라이브 아이콘 확인 → 로그인 → [설정]에서 폴더 다시 지정 |
| 업무일지 폴더가 비어 있습니다 | 시트가 다른 폴더에 있음 | 국장 시트를 `SoneFM 업무일지` 폴더로 옮기기 |
| **업무일지에 최근 N일 안의 내용이 없습니다** | 국장이 **폴더 밖에 새 시트**를 만들었거나, 며칠 업무일지를 안 씀 | 국장께 새 시트 위치 확인 → 폴더 안으로 옮기기. 급하면 [설정] → 업무일지 시트 링크에 새 시트 주소 붙여 넣기 |
| 업무일지 시트를 열 권한이 없습니다 / 공유되어 있지 않습니다 | 폴더·시트 공유가 "제한됨" | 시트(또는 폴더) 공유 → **링크가 있는 모든 사용자: 뷰어** |
| 인터넷 연결을 확인하세요 | 인터넷 끊김 | 연결 후 [새로고침]. 급하면 [업무 추가]로 직접 입력 |
| 업무일지에서 업무를 찾지 못했습니다 | 시트 모양이 크게 바뀜 | 한 줄에 업무 하나, 날짜는 날짜 칸이나 날짜만 있는 줄로. 안 되면 직접 입력하고 개발자에게 시트 모양 알리기 |

설정의 **업무일지 시트 링크**에 주소를 넣으면 폴더보다 그 시트를 먼저 봅니다. 폴더 방식으로 돌아가려면 링크 칸을 비우세요.

## 편성

| 화면 안내 | 할 일 |
|---|---|
| 편성 폴더에 편성 데이터 파일(.db)이 없습니다 | 편성 담당께 편성표 앱 **설정 → 데이터 내보내기**로 `SoneFM 편성` 폴더에 저장 부탁 |
| 새 편성 파일(…)을 쓸 수 없어 이전 편성을 씁니다 | 동기화 중이었을 수 있습니다. 1~2분 뒤 [새로고침]. 계속되면 다시 내보내기 부탁 |
| 더 새 버전의 프로그램에서 만든 데이터 파일입니다 | 이 PC의 **편성표 앱을 업데이트**(편성 담당 PC와 같은 버전으로) |
| 편성표 앱을 찾지 못해 … | 편성표 앱 설치 |
| 결과에 "○월 편성은 아직 '작성중' 상태입니다" | 편성 담당이 확정 전에 내보낸 것. 회차가 바뀔 수 있으니 확정 후 다시 받기 |
| 1단계에서 실패: …는 편성표에 빈칸입니다 | 날짜·시각을 잘못 넣었거나 그 칸이 비어 있음. 편성표 앱에서 확인 |

편성 폴더를 비워 두면 **이 PC의 편성표 앱 데이터**를 씁니다(같은 PC에서 편성까지 할 때).

## 앱 실행

| 화면 안내 | 할 일 |
|---|---|
| 'radio2yt' 앱을 찾지 못했습니다 (또는 다른 앱 이름) | 그 앱 설치. 설치했는데도 안 보이면 [설정] → 앱 폴더에 설치 폴더(`C:\Users\<이름>\AppData\Local\Programs\SoneFM 유튜브 편집기`) 넣기 |
| 실행 파일을 찾지 못했습니다 | 앱 다시 설치 |
| 이 앱은 계약 버전 N을 씁니다 … 플랫폼을 업데이트하세요 | 업무자동화 프로그램을 최신으로 설치 |
| 시간 초과: …초 안에 끝나지 않아 멈췄습니다 | 송출 파일이 너무 크거나 PC가 바쁨. 다른 프로그램을 닫고 다시 실행. 계속되면 그 앱을 단독으로 실행해 보기 |
| 결과를 남기지 않고 끝났습니다 | 앱이 비정상 종료. 안내 아래 붙은 로그 몇 줄과 `platform.log`를 개발자에게 |
| 2단계에서 실패: 썸네일 파일을 찾지 못했습니다 | 썸네일 칸의 파일이 옮겨지거나 지워짐 → [찾기]로 다시 고르기 |
| 유튜브 업로드 … 건너뜀 | 자동 업로드는 꺼져 있는 것이 정상입니다. 직접 업로드하세요 |

**실패한 업무는 [다시 실행]으로 다시 할 수 있습니다.** 이미 만든 파일은 같은 이름으로 덮어씁니다.

## 프로그램이 안 켜지거나 화면이 하얗게 나올 때

- Windows 10이면 **Microsoft Edge WebView2 런타임**이 필요합니다(Microsoft 사이트에서 "WebView2 Runtime" 검색해 설치). 편성표 앱도 같습니다.
- 백신이 프로그램을 막았는지 확인하고 예외로 등록합니다.
- `platform.log`에 `화면 열림: {"bridge":true …}`가 있으면 화면 연결은 정상입니다. `bridge:false`면 다시 설치합니다.

## 직접 확인하는 방법 (담당자용)

명령 프롬프트에서 각 앱을 직접 불러 볼 수 있습니다. 결과 JSON 한 줄이 나오면 정상입니다.

```
"%LOCALAPPDATA%\Programs\SoneFM편성표\SoneFM.exe" --cli lookup --date 2026-11-17 --hour 11 --result "%TEMP%\r.json"
type "%TEMP%\r.json"
```

`"status": "ok"`면 정상이고, `"message"`에 이유가 적혀 있습니다.
